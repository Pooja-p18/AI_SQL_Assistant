# AI SQL Assistant

An AI-powered SQL Assistant that converts natural language into SQL queries using Google's Gemini LLM.

## Tech Stack

- Python
- PostgreSQL
- Streamlit
- Google Gemini API
- Pandas
- Plotly

## Features

- Natural language to SQL
- PostgreSQL query execution
- Interactive Streamlit dashboard
- SQL validation
- Data visualization
- AI-powered query explanations
